# DiTing2.0-seismic-classification
This repository provides a self-developed implementation and benchmarking suite for seismic event classification based on the DiTing 2.0 dataset, featuring a DiTing2.0_benchmark_runner module for conducting 3-class (Earthquake, Explosion, and Collapse) and 4-class (including Noise) experiments. To support these benchmarks, EQ_EP_SS_data_set_processing.ipynb and noise_dataset_process.ipynb are included as the dedicated data processing pipeline for the DiTing 2.0 dataset (which requires official application via the National Earthquake Data Center). The project also features an automated Seismic Event Classification System prototype in a separate folder, utilizing the MSH dataset from Zenodo. As a comprehensive technical supplement for the entire research, the Additional_code directory contains various alternative model architectures and experimental frameworks explored during the study.
