# DiTing2.0-seismic-classification
This repository provides the official implementation and benchmarking suite for seismic event classification based on the DiTing 2.0 dataset, featuring a DiTing2.0_benchmark_runner module for conducting 3-class (Earthquake, Explosion, and Collapse) and 4-class (including Noise) experiments. To support these benchmarks, EQ_EP_SS_data_set_processing.ipynb and noise_dataset_process.ipynb are provided as the dedicated data processing pipeline for the DiTing 2.0 dataset (which must be officially requested via the National Earthquake Data Center). The project also includes an automated Seismic Event Classification System prototype in a separate folder, utilizing the MSH dataset from Zenodo. As a comprehensive technical supplement for both the DiTing experiments and the classification system, the Additional_code directory contains various alternative model architectures and experimental frameworks explored throughout the entire study.
